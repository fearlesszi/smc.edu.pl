馆藏建设原则

  • 尊重著作权、许可条款、隐私，以及作者与出版者的合法权益。

申请建议

  1. 先阅读 GitHub Student Developer Pack 官方资格说明并提交申请。
  2. 再分别查看 JetBrains、Notion、Figma、Microsoft Azure 与 Microsoft 365 的教育计划。
  3. 如域名或机构未被自动识别，联系平台客服并按要求提交真实有效的在读材料；不得制作或修改证明文件。

教育邮箱使用指南

  1. 仅在 SMC 已实际开通并向你分配有效邮箱、且你的学员身份已确认后使用该邮箱。
  2. 在第三方平台选择学生或教育计划，填写真实的学校邮箱，并完成平台发出的邮箱验证。
  3. 若系统无法识别学校域名，联系平台官方支持，按要求提交 SMC 实际出具的在读证明。不得自行制作或修改证明。
