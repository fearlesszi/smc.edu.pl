Die SMC-Bibliothek

Ein kuratierter Leseraum, der Grundlagentexte, Forschungskompetenz, Primärquellen und interdisziplinäre Lernpfade verbindet.

Grundsätze des Bestandsaufbaus

  • Primärquellen, wissenschaftliche Editionen und transparente Forschungsrepositorien bevorzugen.
  • Bibliografische Metadaten und dauerhafte Identifikatoren angeben, soweit verfügbar.
  • Urheberrecht, Lizenzbedingungen, Privatsphäre sowie die Rechte von Autorinnen, Autoren und Verlagen achten.
  • Empfohlene Lektüre von den verbindlich in einem Kurs verwendeten Materialien unterscheiden.

Institutional identity clarification
This website identifies as Sovereign Modern College. It is distinct from Malta-based Signum Magnum College. MFHEA institution licence 2019-014 belongs to Signum Magnum College and must not be represented as a licence held by this website merely because both use the initials “SMC”. State the actual institution accurately when applying for education offers. MFHEA quality audit report · WHED institutional record

Suggested application order

  1. Read the official GitHub Student Developer Pack eligibility rules and apply.
  2. Then review education programmes from JetBrains, Notion, Figma, Microsoft Azure and Microsoft 365 individually.
  3. If the domain or institution is not recognised automatically, contact the provider and submit only genuine, current enrolment evidence if requested. Never create or alter proof documents.

Using an SMC education email

  1. Use an SMC address only after SMC has actually provisioned it to you and confirmed your current learner status.
  2. Select the provider’s student or education plan, enter your real school address and complete the provider’s email verification.
  3. If the domain is not recognised, contact the provider and submit genuine enrolment evidence issued by SMC if requested. Never create or alter proof documents.
