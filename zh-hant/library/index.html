SMC 學術圖書館

以策展式閱讀路徑連結基礎經典、研究素養、原始文獻與跨學科主題。館藏書目將在版權與版本核查後逐步公布。

館藏建置原則

  • 優先採用第一手資料、學術校勘版本與透明開放的研究知識庫。
  • 在條件允許時提供完整書目中介資料與穩定識別碼。
  • 尊重著作權、授權條款、隱私，以及作者與出版者的合法權益。
  • 明確區分推薦閱讀材料與正式納入課程的指定文獻。

申請建議

  1. 先閱讀 GitHub Student Developer Pack 官方資格說明並提出申請。
  2. 再分別查看 JetBrains、Notion、Figma、Microsoft Azure 與 Microsoft 365 教育方案。
  3. 若網域或機構未被自動識別，請聯絡平台客服並依要求提交真實有效的在學資料；不得製作或修改證明文件。

教育信箱使用指南

  1. 僅在 SMC 已實際開通並分配有效信箱、且你的學員身分已確認後使用該信箱。
  2. 在第三方平台選擇學生或教育方案，填寫真實學校信箱並完成平台寄送的信箱驗證。
  3. 若系統無法識別學校網域，請聯絡平台官方支援，依要求提交 SMC 實際開立的在學證明。不得自行製作或修改證明。
