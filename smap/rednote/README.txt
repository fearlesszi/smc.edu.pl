小红书全功能地图 / REDNOTE FUNCTION MAP

部署
1. 解压 rednote-function-map.zip。
2. 将文件夹内全部文件上传至网站目录：/smap/rednote/
3. 确保 index.html 位于该目录根部。
4. 访问 https://smc.edu.pl/smap/rednote

文件
- index.html       页面结构、SEO 元数据、社交分享元数据
- styles.css       全屏响应式 UI
- app.js           平面地图渲染、缩放、拖动、搜索、复制链接
- map-data.js      页面运行使用的功能数据
- map-data.json    可编辑的独立功能数据
- rednote.svg      小红书标志 SVG
- robots.txt       搜索引擎抓取规则
- sitemap.xml      页面站点地图

交互
- 鼠标滚轮 / 触控板：以指针位置为中心缩放
- 鼠标 / 触摸拖动：平移地图
- 右下角 + / -：缩放
- 右下角框角按钮：适配全图
- 搜索框：按功能名称或说明筛选地图内容
- 左上角小红书标志：复制 https://smc.edu.pl/smap/rednote
- 左下角 SMC 标志：在新窗口打开 https://smc.edu.pl/
- 键盘：+ / - 缩放，0 适配全图，方向键平移

数据说明
功能内容依据提供的《小红书全功能地图.md》整理并导入，保留 16 个分类及其功能项。平台功能、入口、价格与权限等信息沿用原文，未在本网页中进行实时核验。

品牌与图标
- 小红书标志使用 Simple Icons 项目中的 Xiaohongshu 单色 SVG 图形作为网页标识；品牌及商标权归其权利人所有。
- 左下角 SMC 图标引用用户指定的主站 SVG 地址，显示尺寸限制为 24×24 px。
- Favicon 参考主站域名 favicon.ico，并同时声明主站 SMC 蓝色 crest SVG。

SEO
页面包含 title、description、keywords、author、robots、canonical、Open Graph、Twitter Card、theme-color、favicon，以及 robots.txt / sitemap.xml。
